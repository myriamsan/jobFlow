# jobFlow

JobFlow est une application Web de suivi de candidature. 


### Pourquoi ce projet 

Le projet jobFlow a pour but d'enrichir mon portfolio. J'aimerais aussi qu'à l'avenir  cette web app soit utilisée pour accompagner les personnes dans leur recherche d'emploi

### Stack technique

Le projet est principalement basé sur les stacks suivantes : SpringBoot et java pour le backend , Angular pour le Frontend et mysql pour la base de données
